<a name="português"></a>
## 🇧🇷 Português

Um jogo interativo de **aventura baseada em texto** desenvolvido para web, onde o jogador enfrenta enigmas, desafios lógicos e toma decisões que alteram diretamente o rumo e o desfecho da história.

🔗 **Acesse o projeto online:** [brunossilva12-creator.github.io/CalculadoraDeAventura](https://brunossilva12-creator.github.io/CalculadoraDeAventura/)

### ✨ Funcionalidades
- **Narrativa Interativa (Escolha seu Destino):** Sistema de ramificações onde cada decisão tomada pelo jogador leva a diferentes caminhos e consequências.
- **Enigmas e Desafios:** Testes de raciocínio integrados à história para avançar na jornada.
- **Feedback Dinâmico na Tela:** Atualização instantânea dos cenários e opções diretamente no navegador sem recarregar a página.

### 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação da tela inicial, botões de ação e área de exibição da narrativa.
- **CSS3:** Estilização temática da interface, botões interativos e layout responsivo.
- **JavaScript:** Lógica principal do jogo, controle de estados, estruturas condicionais e manipulação dinâmica do DOM.

### 🚀 Como executar localmente
1. Clone este repositório:
   ```bash
   git clone https://github.com/brunossilva12-creator/CalculadoraDeAventura
   ```
2. Abra a pasta do projeto e execute o arquivo `index.html` diretamente no seu navegador.

<a name="english"></a>
## 🇺🇸 English

An interactive **text-based adventure game** built for the web, where players solve riddles, overcome logic challenges, and make decisions that directly shape the storyline and its outcomes.

🔗 **Live Demo:** [brunossilva12-creator.github.io/CalculadoraDeAventura](https://brunossilva12-creator.github.io/CalculadoraDeAventura/)

### ✨ Features
- **Interactive Branching Narrative:** Decision-driven gameplay where every choice leads to different paths and consequences.
- **Riddles & Logic Challenges:** Integrated puzzles that players must solve to progress through the journey.
- **Dynamic UI Updates:** Instant rendering of story stages and choices directly in the browser without page reloads.

### 🛠️ Technologies Used
- **HTML5:** Structure of the welcome screen, action buttons, and story display area.
- **CSS3:** Thematic interface styling, interactive buttons, and responsive layout.
- **JavaScript:** Core game logic, state management, conditional branching, and dynamic DOM manipulation.

### 🚀 How to run locally
1. Clone this repository:
   ```bash
   git clone https://github.com/brunossilva12-creator/CalculadoraDeAventura
   ```
2. Open the project folder and launch the `index.html` file in your browser.
